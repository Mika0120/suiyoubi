# Oshi-Coord AI（MVPプロトタイプ）

「明日の天気」×「推しの概念（画像）」×「自分の骨格」を掛け合わせ、最適な全身コーディネートをSHEINやZOZOTOWNから自動提案・即時購入できる【購買体験特化型】AIスタイリストWebアプリのMVPです。

## 実装された主要機能

1. **画像認識 × 推し活検索（Vision API / ローカルCanvas解析）**
   - アップロード画像（またはサンプルプリセット）からメインカラー3色（HEX＋色名）、推奨素材感、雰囲気（Vibe）を抽出。
   - Gemini APIキーを設定すると Gemini Vision API で解析、未設定時はブラウザのCanvas色抽出＋推論エンジンで即時動作します。
2. **天気・気温API連携（OpenWeatherMap / 気象シミュレーション）**
   - 指定した「予定日」と「地域（東京・大阪・ソウル等）」の気温・天候を取得し、アウターの要否や撥水・防寒アイテムを判定します。
3. **骨格タイプ × パーソナライズフィルター**
   - `骨格ストレート` / `骨格ウェーブ` / `骨格ナチュラル` に合わせて不向きな形状・素材を自動除外し、選定理由を表示します。
4. **アフィリエイト連携・購買直結**
   - 予算上限内で「トップス・ボトムス・（アウター）・シューズ/小物」の3〜4点セットを提案し、SHEIN / ZOZOTOWN のアフィリエイトパラメータ付き購入リンクを生成します。

## 起動方法

Python 3 標準ライブラリのみで動作するため、追加パッケージのインストールは不要です。

```bash
cd /Users/kazuki/.gemini/antigravity/scratch/oshi-coord-ai
python3 server.py
```

ブラウザで `http://127.0.0.1:8000` を開いてください。

## 本番API連携（任意）

環境変数、または画面右上の「⚙ API設定」モーダルから以下を指定できます：
- `GEMINI_API_KEY`: Google Gemini Vision API キー
- `OPENWEATHER_API_KEY`: OpenWeatherMap API キー
- `OSHI_AFFILIATE_ID`: アフィリエイトトラッキングID
